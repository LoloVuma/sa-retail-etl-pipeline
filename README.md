# South African Retail Sales ETL Pipeline

## Project Overview

This project aims to build an ETL pipeline using Python, SQL, and Power BI to process and analyse South African retail trade sales data.

The pipeline will extract data from a CSV file, clean and transform the data using Python, load it into a database, and present useful insights through a dashboard.

## Business Objectives

- Clean and validate retail sales data.
- Store structured data in a database.
- Analyse retail sales trends over time.
- Present findings through a dashboard.

## Technologies

- Python
- Pandas
- SQL
- Power BI
- Git and GitHub

## Data Source

[South African Retail Sales Analysis](https://github.com/naledi901/South-African-Retail-Sales-Analysis)

The dataset's columns, measures, and units will be documented after data inspection.

## ETL Pipeline

The pipeline will follow these steps:

1. **Extract:** Read retail sales data from a CSV file using Python.
2. **Transform:** Clean the data, handle missing values, and prepare it for analysis.
3. **Load:** Store the cleaned data in a SQL database.
4. **Analyse:** Use SQL queries to identify retail sales trends.
5. **Visualise:** Build a Power BI dashboard to present key findings.
